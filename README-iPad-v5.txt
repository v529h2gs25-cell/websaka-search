WEBサカ選手検索 v5（段階導入版）

今回のZIPは、既存のv4を元に以下を追加しています。
- ピッチ上の11枠から名前検索で選手を配置し、ブラウザに保存
- WEBサカWIKIのフォーメーション別・ポジション別の試合数、評価点、偏差値、得点、アシストを取得
- 初期対応は「ブラジル 2014」「カテナチオ」「日本 2001」の3フォーメーション
- 最低出場試合数を指定して候補を順位付け
- ピッチ枠ごとの「Wiki番号」を手動で合わせられる（初期番号は仮）
- v4のお気に入り、比較、選手検索、自動更新は維持

【iPadでGitHub更新】
1. ZIPを解凍する。
2. GitHubのリポジトリで index.html と .github/workflows/update-players.yml を各ファイルの鉛筆マークで編集して置き換える。
3. 新規ファイル collect_formations.py をリポジトリ直下にアップロードする。
4. collect.py と players.json は変更・削除しない。
5. Actions → Update WEBsaka players → Run workflow を実行する。
6. 全ステップが成功すると formations.json が新規作成され、サイトのマイチームに実績が表示される。

【注意】
- 現在のWEBサカWIKIでは「ブラジル 2014 (4-2-3-1)」を確認しています。ユーザーのスクリーンショットの「ブラジル 4-2-3-1」と同一のゲーム内配置かどうかは未検証です。
- WIKIポジション番号はゲーム内の「GKから順に割り振る」の番号と対応。画面上の枠との紐付けは手動で設定してください。
- collect_formations.py はこの環境で実際のサイトへの通信実行はできていないため、初回Actions実行時のHTML解析テストが必要です。
- WIKIに載るデータは集計実績であり、将来の成績の保証ではありません。
- 収集先の規約・robots.txtを確認し、負荷を尊重してください。対象を増やす際は慎重に。
